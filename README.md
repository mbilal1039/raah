# Raah (راہ)

Bilingual career guidance platform for students after 10th grade.

## Stack
- Frontend: HTML/CSS/vanilla JS (in `public/`)
- Backend: Node.js + Express
- DB: SQLite (better-sqlite3)
- Auth: bcrypt + JWT (HttpOnly cookie)

## Run locally
    npm install
    npm run seed
    npm run dev

Open http://localhost:3000
